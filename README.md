# System-Checker

Prüft jedes Produktivitätssystem (Routine, Habit Tracker, Lernplan, Trainingsplan …) auf Schwachstellen und gibt dir maximal 3 konkrete Fixes.

Die Downloads findest du unter **Releases** (rechts auf dieser Seite):

- `System-Checker-Skill.zip` – Skill für Claude oder Claude Code
- `System-Checker-Prompt.txt` – derselbe Check als Prompt für jede KI
- `System-Check-Protokoll.pdf` – derselbe Check zum Ausfüllen von Hand
- `System-Checker-Anleitung.pdf` – die drei Wege auf einer Seite
